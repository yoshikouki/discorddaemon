# Security Policy

## Supported Versions

Only the latest `main` branch and the latest released version are supported for security updates.

## Reporting a Vulnerability

If GitHub Security Advisories are enabled for this repository, please report vulnerabilities privately using a security advisory.

If private advisories are not available, open a GitHub issue with only minimal sensitive detail. Please avoid posting exploit code, secrets, tokens, private server details, or information that would make active abuse easier.

## Response Expectations

I will try to acknowledge security reports within a few days. After confirming the issue, I will work on a fix or mitigation and share updates when there is meaningful progress.
